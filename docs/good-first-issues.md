# Candidate good first issues

These are issue drafts, not claims that labels or issues already exist on GitHub.
When publishing, label them `good first issue` and link the relevant guide.

- **Document a custom validation hook (EN/PT).** Add a runnable example using an
  existing API; done when both docs build and the example compiles in supported Go.
- **Show HTTP ETag editing with curl (EN/PT).** Explain 428, 412 and successful
  PATCH; done when all commands match the local SQLite quickstart.
- **Improve a validation error example.** Add one minimal reproduction for an
  existing rule, explain its response, and test the observed contract without
  changing public behavior.
