# Security policy

See [supported versions](COMPATIBILITY.md#supported-releases). Before v1, security
fixes target the latest minor's newest patch. After v1, the two latest minors of
the current major receive fixes and the previous major's final minor receives
security fixes for six months after a new major is released.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/Gui-Rondon/hyrule/security/advisories/new).
Do not disclose exploit details in public issues. Include affected versions,
reproduction, impact, configuration and a minimal proof of concept where possible.
Do not include credentials or other people's personal data.

The actively maintained project aims to acknowledge reports within **seven
calendar days**. This is an initial response target, not a guaranteed fix deadline.
Gui-Rondon will coordinate investigation, affected releases, mitigation, a fix and
public advisory with the reporter. Acknowledgement and disclosure timing will be
communicated privately. Older unsupported versions receive upgrade guidance.

Gui-Rondon is the sole responder and may use AI assistance for triage and
investigation. Responsibility for acknowledgement, remediation and disclosure
remains with Gui-Rondon; AI assistance is not independent human review.
