# Code of conduct

Everyone participating in Hyrule is expected to be respectful, constructive and
welcoming. Discuss technical choices in good faith; accept feedback and make space
for contributors of different backgrounds and experience levels.

Harassment, discriminatory language, threats, sexual attention, personal attacks
and publishing private information without permission are unacceptable.

Gui-Rondon currently moderates project spaces. For a private conduct report, use
[the maintainer's GitHub profile](https://github.com/Gui-Rondon) to request a private
contact without posting sensitive details publicly. GitHub's report-abuse tools
are available for violations of GitHub policy. The security vulnerability channel
is reserved for vulnerabilities. A dedicated independent conduct contact will be
added when additional maintainers join.

Moderation may include requesting an edit, removing content, temporarily limiting
participation or banning repeated/severe misconduct. The maintainer will explain
an action privately when possible and protect reporter privacy.
